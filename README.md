Aplikacja-REST

Repozytorium zawiera projekty realizowane w ramach laboratoriów dotyczących tworzenia aplikacji REST w technologii Java i Spring Boot.

Struktura repozytorium
project-rest-api (lab1)

Projekt aplikacji REST API zrealizowany z wykorzystaniem:

Java
Spring Boot
Spring Web
Spring Data JPA
PostgreSQL

Funkcjonalności:

obsługa endpointów REST,
operacje CRUD,
komunikacja z bazą danych,
testowanie endpointów przy użyciu Postmana.

Technologie:

Java

Funkcjonalności:

reaktywne endpointy REST,
konteneryzacja aplikacji,
uruchamianie środowiska przy pomocy Docker Compose,
komunikacja z bazą PostgreSQL.
